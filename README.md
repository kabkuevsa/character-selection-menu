# Character Selector Game 🎮

Профессиональное консольное приложение на C# для демонстрации принципов ООП и паттернов проектирования.

## 📋 О проекте

позволяет выбирать персонажей , просматривать их характеристики и навыки. Проект разработан как демонстрация навыков программирования на C# для портфолио.

## ✨ Особенности

- ✅ **Чистая архитектура** - разделение ответственности между классами
- ✅ **Полноценное ООП** - наследование, инкапсуляция, полиморфизм
- ✅ **Интерактивное консольное меню** - удобный пользовательский интерфейс
- ✅ **Расширяемость** - легко добавлять новых персонажей
